This lecture is a short demo on how to use Markdown and [Quarto](https://quarto.org/) to create reproducible documents, e.g. quality control or result reports. 

Quarto (not to be confused with [Quattro](https://www.quattroodenplan.se/)) is an update of the original R Markdown, and comes pre-installed in Positron. It is great for creating documents that can include code, text, and figures, rendered directly from your data.

For markdown, check out [this useful cheat sheet](https://www.markdownguide.org/cheat-sheet/)
