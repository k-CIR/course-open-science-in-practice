
R is the programming language we use for most of the course. Positron is the IDE we use to write and run R code, but R itself is not installed automatically with Positron. 

If you do not have R installed, go to: [CRAN (Comprehensive R Archive Network)](https://cran.r-project.org/) and follow the instructions for your operating system. Do not forget to admire the beauty of the CRAN website while you are there.
