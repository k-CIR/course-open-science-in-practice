# Exercises

Passing the course require:

1. Active participation in lectures, excercises/workshops and the final examination seminar
2. Completion of a mini-project
3. Presenting your project in the examination seminar

Navigate to the instructions for the different exercise/workshops in the menu to the left.

The pages for [your mini-project](../project/project-description.md) and the [examination seminar](../project/project-examination.md) give detailed information about what is expected of you in the course for receivng a passing grade.

??? top "More Git?"
    Git is very well documented and due to its large user base there is an abundance of learning material and tutorials. Here are a few examples:

    With `git --help` you can see available commands and each command has its own extensive documentation e.g. `git switch --help`. Press `q` to exit help pages.

    [Git Pro](https://git-scm.com/book/en/v2) can be downloaded for free as pdf or e-book. Although more than a decade old it covers most you need to know.

    [Git Crash Course](https://www.youtube.com/playlist?list=PL4cUxeGkcC9j2pbmcA93DR1A3m7VEgSxK) by Net Ninja has excellent tutorials.
